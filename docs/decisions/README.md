# Registro de decisiones técnicas

Esta carpeta contiene decisiones de arquitectura (ADR) que afecten contratos, formatos, modelos, índices, reproducibilidad o entrega.

Use un archivo por decisión:

```text
NNNN-titulo-breve.md
```

Cada registro debe incluir contexto, decisión, alternativas, consecuencias, fecha y responsables. La presencia de `.gitkeep` conserva la estructura solicitada mientras no existan ADR aprobados.
