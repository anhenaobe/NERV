9. CURRENT EXCLUSION LOGIC

src/nerv/ingestion/lector_corpus.py defines ARCHIVOS_AUXILIARES with explicit
filenames including Extracto_Preguntas_50_v2.pdf. That main exclusion applies
only when the candidate is directly under the corpus root. It is a
filename-specific list, not a general auxiliary-artifact policy.

FASE ORDENADA CODEFEST.xlsx was admitted because it is nested under
F3_Dinamicas_Territoriales and is not in ARCHIVOS_AUXILIARES.

The current checkout also names this source in
src/nerv/evaluation/contamination.py, but the only caller found is
scripts/preparar_para_colab.py. The accepted production pipeline does not call
that filter before publishing documents/chunks, so it did not protect these
accepted artifacts.
