# Archivo histórico

Este directorio conserva documentación y scaffolding anteriores a la
consolidación de la raíz del repositorio. Los archivos pueden mencionar la
estructura histórica `NERV/NERV`, rutas de OneDrive o contratos ya superados;
se conservan como evidencia y no describen la ejecución vigente.

La documentación actual comienza en el [README del proyecto](../../README.md)
y en [docs/architecture](../architecture/).
