7. ROOT CAUSE

C. INGESTION CODE REGRESSION

Commit 25ff615 introduced paginas_ocr_fallidas in leer_pdf and raised a
document-level ValueError whenever any page returned empty OCR text. The
accepted behavior retained a PDF if other pages supplied useful text. The
clean run's 84 errors are exactly emitted by that new fatal branch. This made
an expected blank/non-text page fatal to the entire mixed or OCR-driven PDF.

9. FIX

Implemented the minimum ingestion fix in
src/nerv/ingestion/lector_corpus.py:

- an empty OCR result for one page is recorded as paginas_sin_texto but does
  not invalidate useful text from other pages;
- a PDF still fails if the entire document has no useful text;
- a real ValueError from page rendering or OCR is now propagated clearly
  instead of being converted silently into an empty result.

No chunking code, OCR routing, language configuration, exclusion rule, or
production artifact was changed.
