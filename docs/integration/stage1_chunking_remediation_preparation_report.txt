STAGE-1 CHUNKING REMEDIATION PREPARATION REPORT
================================================

1. ROOT CAUSE
-------------
Accepted PDF text retains PyMuPDF line/page extraction newlines. PySBD 0.3.4
emits those newline-delimited fragments as independent units even when the left
side has no valid linguistic ending and the right side continues it. Chunk
packing correctly preserves its input units, so the defect enters before
packing. A second bounded pattern occurs under continuous whitespace where
PySBD separates lowercase enumerated/abbreviation continuations. The 510-token
hard limit was not the root cause.

3. FAILURE PATTERNS
-------------------
Pattern A - PDF single-line extraction wrap
Population: 179 of the 184 known official-result PDF boundaries; part of the
33,615 full-audit source-extraction boundaries.
Failure: PySBD treats the extraction newline as a completed unit boundary.
Correction: merge only a non-terminal PDF unit with the next extracted unit
when lexical continuation, page-label provenance, or a prose-line signal makes
the ending unsafe.

Pattern B - PDF page/blank-line heading or footnote interruption
Population: 5 of the 184 known official-result PDF boundaries.
Failure: a page/blank separator leaves a short heading, label, comma-ended
clause, or footnote interruption as a stored ending.
Correction: attach the deterministic short non-terminal structural prefix or
footnote interruption to its following content; do not invent punctuation.

Pattern C - continuous-whitespace PySBD continuation
Population: exactly 81 boundaries across 53 documents (78 PDF, 3 JSON).
Failure: PySBD separates enumerators, abbreviations, legal references, and
similar spans even though the next new content starts lowercase under
continuous whitespace.
Correction: source-order post-segmentation reconciliation merges the adjacent
units only when the continuous boundary has proven lexical continuation.

Pattern D - genuine sentence boundary / structural field boundary
Population: control fixtures and five already-correct PDF documents.
Failure: none.
Correction: terminal punctuation remains authoritative; newline-delimited JSON
field labels and tabular rows remain independent structural units.

4. CODE FIX
-----------
src/nerv/chunking/sentence_splitter.py now performs document-format-aware,
source-order reconciliation after bounded PySBD segmentation. It retains PDF
newline provenance, recognizes page labels and non-terminal prose/structural
prefixes, rejects JSON field starts, and merges only deterministic invalid
boundaries. Content is only whitespace-joined; no word or punctuation is
invented.

src/nerv/chunking/pipeline.py passes document format into segmentation and
checks reconstructed PDF/TXT units before packing. The frozen 256 target,
32-token overlap, and effective 510-token limit are unchanged.

GENUINE_OVERSIZED_SENTENCE_BLOCKER.
